# แผนที่เครือข่ายอารักขาพืช จังหวัดเพชรบูรณ์

เว็บแอปแสดง **ศูนย์จัดการดินปุ๋ยชุมชน (ศดปช.) · ศูนย์จัดการศัตรูพืชชุมชน (ศจช.) · แปลงพยากรณ์ · โรงเรียนเกษตรกร · จุดบริการคลินิกพืช** บนแผนที่
บุคคลทั่วไปเข้าดูได้โดยไม่ต้องล็อกอิน ส่วนเจ้าหน้าที่อารักขาพืชล็อกอินเพื่อเพิ่ม แก้ไข หรือลบข้อมูลได้เอง หน้าเว็บของทุกคนจะเปลี่ยนตามทันทีโดยไม่ต้องแก้โค้ด

**เทคโนโลยี:** React + Vite · Tailwind CSS · Framer Motion (อนิเมชั่น) · Leaflet + OpenStreetMap (ฟรี ไม่ต้องใช้ API key) · Supabase (ฐานข้อมูล ระบบล็อกอิน เก็บรูป และอัปเดตแบบเรียลไทม์) · Vercel (โฮสต์เว็บ)

## ขั้นตอนติดตั้ง

### 1) สร้างฐานข้อมูล Supabase (ฟรี)
1. สมัครที่ https://supabase.com แล้วกด **New project** (เลือก Region: Singapore)
2. ไปที่ **SQL Editor > New query** วางเนื้อหาไฟล์ `supabase/schema.sql` แล้วกด **Run**
3. สร้าง query ใหม่ วางไฟล์ `supabase/seed.sql` แล้วกด **Run** (นำเข้าข้อมูลตั้งต้น 155 จุด)
4. สร้างบัญชีแอดมิน: **Authentication > Users > Add user** ใส่อีเมลและรหัสผ่าน แล้วติ๊ก *Auto Confirm User*
5. กลับไปที่ SQL Editor แล้วรันคำสั่งนี้ (เปลี่ยนอีเมลเป็นของจริง) เพื่อให้สิทธิ์แอดมิน
   ```sql
   insert into public.admins (user_id, email)
   select id, email from auth.users where email = 'อีเมลแอดมิน@gmail.com'
   on conflict do nothing;
   ```
   เพิ่มแอดมินคนอื่นได้ด้วยการทำข้อ 4 และ 5 ซ้ำ
6. ไปที่ **Project Settings > API** แล้วคัดลอก `Project URL` และ `anon public key` ไว้ใช้ในขั้นตอนถัดไป

### 2) เปิดบน StackBlitz
- อัปโหลดโปรเจกต์นี้ขึ้น GitHub ก่อน (ดูข้อ 3) แล้วเปิดลิงก์ `https://stackblitz.com/github/<ชื่อผู้ใช้>/<ชื่อ repo>`
  หรือลากโฟลเดอร์ทั้งหมดไปวางใน StackBlitz (เลือกเทมเพลต Vite + React)
- สร้างไฟล์ `.env` (ดูตัวอย่างจาก `.env.example`) แล้วใส่ค่า
  ```
  VITE_SUPABASE_URL=https://xxxx.supabase.co
  VITE_SUPABASE_ANON_KEY=eyJ...
  ```
- ถ้ารันเองบนเครื่อง ใช้คำสั่ง `npm install` แล้วตามด้วย `npm run dev`

### 3) อัปโหลดขึ้น GitHub
```bash
git init
git add .
git commit -m "first version"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/pp-phetchabun.git
git push -u origin main
```
ไฟล์ `.env` จะไม่ถูกอัปโหลด เพราะกำหนดไว้ใน `.gitignore` แล้ว

### 4) Deploy ด้วย Vercel
1. ที่ https://vercel.com กด **Add New > Project** แล้วเลือก repo จาก GitHub
2. ระบบจะตรวจพบว่าเป็นโปรเจกต์ Vite เอง ไม่ต้องเปลี่ยนการตั้งค่า build
3. ที่หัวข้อ **Environment Variables** ใส่ `VITE_SUPABASE_URL` และ `VITE_SUPABASE_ANON_KEY`
4. กด **Deploy** หลังจากนี้ทุกครั้งที่ push ขึ้น GitHub ระบบจะ deploy ใหม่ให้อัตโนมัติ

> การเพิ่มหรือแก้**ข้อมูล**ผ่านหน้าแอดมินไม่ต้อง deploy ใหม่ ต้อง deploy เฉพาะเมื่อแก้**โค้ด**เท่านั้น

## ข้อควรรู้
- **Supabase แบบฟรีจะหยุดโปรเจกต์ชั่วคราว** ถ้าไม่มีการใช้งานติดต่อกันประมาณ 7 วัน เปิดคืนได้จากหน้า Dashboard ถ้าใช้งานจริงควรมีคนเข้าเว็บเป็นประจำ หรือพิจารณาอัปเกรดแพ็กเกจ
- **ข้อมูลส่วนบุคคล:** ข้อมูลแปลงพยากรณ์ที่นำเข้า**ไม่มี**ชื่อเกษตรกรและเลขบัตรประชาชน เก็บเฉพาะพืช พันธุ์ ที่ตั้ง (หมู่/ตำบล) และพิกัด
- **ศจช.** แสดงชื่อและเบอร์โทรของประธานศูนย์ตามทำเนียบ ถ้าไม่ต้องการแสดงต่อสาธารณะ ลบออกได้ในหน้าแอดมิน

## รายการที่ควรตรวจหลังติดตั้ง
- [ ] **พิกัดคลินิกพืช 12 จุด** ตอนนี้เป็นค่าประมาณบริเวณตัวอำเภอ ควรเปิดหน้าแก้ไขแล้วลากหมุดไปที่สำนักงานเกษตรจริง
- [ ] **แปลงพยากรณ์รหัส 10925** (มะขาม ต.ซับเปิบ อ.วังโป่ง) ในระบบต้นทางพิกัดผิด จึงยังไม่แสดงบนแผนที่ (หน้าแอดมินจะแจ้งเตือนไว้)
- [ ] **ศจช.ตำบลดงมูลเหล็ก** ลองจิจูดในระบบต้นทางเป็น 101.66 ซึ่งอาจพิมพ์ผิดจาก 101.16 ควรตรวจสอบ
- [ ] **โรงเรียนเกษตรกร** ยังไม่มีข้อมูล เพิ่มได้ในหน้าแอดมิน หรือนำเข้าจากไฟล์แม่แบบ CSV

## แหล่งข้อมูลตั้งต้น
- ทำเนียบศูนย์จัดการดินปุ๋ยชุมชน (ศูนย์หลัก และศูนย์เครือข่าย) ปี 2567
- ระบบฐานข้อมูลศูนย์จัดการศัตรูพืชชุมชน และระบบติดตามสถานการณ์ระบาดศัตรูพืชรายแปลง (report-ppsf.doae.go.th) ดึงข้อมูลเมื่อ 16 พ.ย. 2569
