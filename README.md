# แผนที่เครือข่ายอารักขาพืช จังหวัดเพชรบูรณ์

เว็บแอปแสดง **ศูนย์จัดการดินปุ๋ยชุมชน (ศดปช.) · ศูนย์จัดการศัตรูพืชชุมชน (ศจช.) · แปลงพยากรณ์ · โรงเรียนเกษตรกร · จุดบริการคลินิกพืช** บนแผนที่
ข้อมูลเก็บใน **Google Sheets** เจ้าหน้าที่แก้ได้ 2 ทาง คือผ่านหน้า "เจ้าหน้าที่" บนเว็บ หรือแก้ในชีตโดยตรง หน้าเว็บอัปเดตเองภายในประมาณ 30 วินาที ไม่ต้องแก้โค้ด
ระบบฟรีทั้งหมด และไม่มีการหยุดเมื่อไม่มีคนใช้งาน

**เทคโนโลยี:** React + Vite · Tailwind CSS · Framer Motion · Leaflet + OpenStreetMap · Google Sheets + Apps Script (ฐานข้อมูลและระบบล็อกอิน) · Google Drive (เก็บรูปและเอกสาร) · Vercel (โฮสต์เว็บ)

## ขั้นตอนติดตั้ง (ประมาณ 15 นาที)

### 1) สร้าง Google Sheet
1. อัปโหลดไฟล์ `google-apps-script/ข้อมูลตั้งต้น-เครือข่ายอารักขาพืช.xlsx` ขึ้น Google Drive
2. ดับเบิลคลิกเปิดไฟล์ แล้วไปที่ **ไฟล์ > บันทึกเป็น Google ชีต** (ต้องเป็น Google ชีตจริง ไม่ใช่ไฟล์ .xlsx)
3. ในชีตที่ได้จะมี 4 แผ่นงาน
   - `sites` ข้อมูลจุดทั้งหมด 155 จุด
   - `categories` ประเภท ชื่อ สี ไอคอน และการแสดงผล
   - `settings` ลิงก์และข้อความหน้าแรก
   - `admins` รายชื่อแอดมิน

### 2) ติดตั้ง Apps Script
1. ในชีต ไปที่ **ส่วนขยาย > Apps Script**
2. ลบโค้ดเดิมทิ้ง แล้ววางเนื้อหาไฟล์ `google-apps-script/Code.gs` ทั้งหมด จากนั้นกด 💾 บันทึก
3. ที่แถบด้านบน เลือกฟังก์ชัน **`setup`** แล้วกด **เรียกใช้**
   - ระบบจะขออนุญาต ให้กด *ตรวจสอบสิทธิ์ > เลือกบัญชี > ขั้นสูง > ไปที่โปรเจกต์ (ไม่ปลอดภัย) > อนุญาต*
   - ข้อความ "ไม่ปลอดภัย" ขึ้นเพราะเป็นสคริปต์ที่เราเขียนเอง ไม่ได้ผ่านการรับรองจาก Google ถือเป็นเรื่องปกติ
   - `setup` จะสร้างโฟลเดอร์เก็บไฟล์ใน Drive ชื่อ "ไฟล์เว็บเครือข่ายอารักขาพืช (อย่าลบ)" และตั้งค่าให้หน้าเว็บอัปเดตเองเมื่อมีคนแก้ข้อมูลในชีต

### 3) ตั้งรหัสผ่านแอดมิน
ในแผ่นงาน `admins` ใส่อีเมลในคอลัมน์ `email` และรหัสผ่านในคอลัมน์ `password` (อย่างน้อย 6 ตัวอักษร) เพิ่มแอดมินได้หลายคนโดยใส่หนึ่งแถวต่อหนึ่งคน
> ⚠️ แชร์ชีตนี้ให้เฉพาะเจ้าหน้าที่ เพราะคนที่เปิดชีตได้จะเห็นรหัสผ่านในแผ่นงาน `admins`

### 4) เผยแพร่เป็นเว็บแอป
1. ใน Apps Script กด **ทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่**
2. ที่ ⚙️ เลือกประเภท **เว็บแอป** แล้วตั้งค่า
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
3. กด **ทำให้ใช้งานได้** แล้วคัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)
4. ทดสอบโดยเปิด `URL/exec?action=data` ในเบราว์เซอร์ ถ้าเห็นข้อมูล JSON แปลว่าใช้งานได้

> **ถ้าแก้โค้ด Code.gs ภายหลัง** ให้ไปที่ *ทำให้ใช้งานได้ > จัดการการทำให้ใช้งานได้ > ✏️ แก้ไข > เวอร์ชัน: เวอร์ชันใหม่ > ทำให้ใช้งานได้* แบบนี้ URL จะยังเหมือนเดิม

### 5) อัปขึ้น GitHub และ Deploy ด้วย Vercel
```bash
git init && git add . && git commit -m "first version"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/pp-phetchabun.git
git push -u origin main
```
จากนั้นที่ https://vercel.com ให้ทำดังนี้
1. กด **Add New > Project** แล้วเลือก repo
2. ที่หัวข้อ **Environment Variables** เพิ่ม `VITE_GAS_URL` = URL จากขั้นตอนที่ 4
3. กด **Deploy**

ถ้าเปิดบน StackBlitz ให้สร้างไฟล์ `.env` แล้วใส่ `VITE_GAS_URL=...` แบบเดียวกัน (ดูตัวอย่างใน `.env.example`)

## การแก้ข้อมูลในชีตโดยตรง
| คอลัมน์ | ความหมาย |
|---|---|
| `category` | รหัสประเภท: `soil`, `cpmc`, `forecast`, `ffs`, `clinic` |
| `lat`, `lng` | พิกัด เช่น 16.4182 และ 101.1569 (คัดลอกจาก Google Maps ได้) |
| `is_published` | ☑ = แสดงบนเว็บ, ☐ = ซ่อน (ตรงกับปุ่มลูกตาในหน้าแอดมิน) |
| `documents` | รายการเอกสาร (รูปแบบ JSON) ควรเพิ่มหรือลบผ่านหน้าแอดมิน |
| `extra` | ข้อมูลเพิ่มเติม (รูปแบบ JSON) |
| `id` | รหัสอ้างอิง **ห้ามแก้** ถ้าเพิ่มแถวเองในชีต เว้นว่างไว้ได้ ระบบจะใส่ให้อัตโนมัติ |

ในแผ่นงาน `categories` คอลัมน์ `is_visible` ใช้ซ่อนหรือแสดงทั้งประเภท

## ข้อควรรู้
- **ความเร็ว:** การเปิดเว็บครั้งแรกอาจใช้เวลา 1–3 วินาที (Apps Script ตอบช้ากว่าฐานข้อมูลทั่วไป) ครั้งต่อไปเว็บจะแสดงข้อมูลที่จำไว้ทันที แล้วจึงดึงข้อมูลใหม่
- **โควตา Google:** Apps Script รับคำขอพร้อมกันได้ประมาณ 30 คำขอต่อบัญชี ระบบมีแคชช่วยอยู่แล้ว จึงเพียงพอสำหรับการใช้งานระดับจังหวัด
- **ไฟล์ที่อัปโหลด** เก็บในโฟลเดอร์ Drive ของบัญชีที่ติดตั้งสคริปต์ และตั้งค่าเป็น "ทุกคนที่มีลิงก์ดูได้" ขนาดไม่เกิน 20 MB ต่อไฟล์
- **ข้อมูลส่วนบุคคล:** ข้อมูลแปลงพยากรณ์ไม่มีชื่อเกษตรกรและเลขบัตรประชาชน ส่วน ศจช. แสดงชื่อและเบอร์โทรประธานตามทำเนียบ

## รายการที่ควรตรวจหลังติดตั้ง
- [ ] พิกัดคลินิกพืช 12 จุด (ตอนนี้เป็นค่าประมาณบริเวณตัวอำเภอ)
- [ ] แปลงพยากรณ์รหัส 10925 (มะขาม ต.ซับเปิบ) พิกัดในระบบต้นทางผิด จึงยังไม่แสดงบนแผนที่
- [ ] ศจช.ตำบลดงมูลเหล็ก ลองจิจูดอาจพิมพ์ผิด (101.66 น่าจะเป็น 101.16)
- [ ] เพิ่มข้อมูลโรงเรียนเกษตรกร
